# UI kit · сайт ballevent.ru

Клик-версия маркетингового сайта «Частные балы», собранная целиком из компонентов системы
(`SiteHeader`, `SegmentCard`, `StepItem`, `QuoteBand`, `CTABand`, `Button`, `TextLink`,
`SectionLabel`, `FormField`, `Wordmark`). Точка входа — `index.html`.

## Экраны

| Файл | Экран | Источник |
| --- | --- | --- |
| `Home.jsx` | Главная: hero на Terra, три шага подготовки, два сегмента, полоса-передышка, финальный CTA | Артборд «05 · Система в деле» — воспроизведён 1:1 по составу и порядку блоков |
| `Process.jsx` | «Как это происходит» | Собран из тех же блоков и того же текста, что и секция подготовки на главной |
| `Evenings.jsx` | «Вечера»: H1 капителью + пара карточек сегментов | Карточки — из артборда «03 · Компоненты» |
| `Contact.jsx` | «Связаться»: форма заявки, состояния focus / error, экран благодарности | Поля — из артборда «03 · Компоненты» |
| `Shell.jsx` | Шапка, футер, обёртка секции, заголовок секции 3+9, плашка под изображение | Шапка — из макета; футер см. ниже |

## Что взаимодействует

- Навигация в шапке переключает экраны; активный пункт выводится на 90% непрозрачности.
- «обсудить вечер» и кнопка в финальной полосе ведут на экран «Связаться».
- Форма проверяет имя и e-mail, показывает состояние `error` терракотой и переходит на экран благодарности.

## Чего в исходных материалах не было — и что с этим сделано

- **Фотографий и видео нет.** Везде, где макет предполагает изображение, стоит пустая
  рамка `MediaPlaceholder` с подписью. Ни одна картинка не сгенерирована.
- **Раздел «О нас» пуст.** Нет ни текста, ни визуала — экран оставлен пустым с явной подписью.
- **Футер в исходниках не задан.** Собран минимально из существующей лексики шапки
  (знак, домен, телефон) — это единственный блок кита, которого нет в макете.
- **Телефон `+7 495 000-00-00` — плейсхолдер** (так же, как в исходном канвасе).
- Значения кегля даны для базового брейкпоинта 1200px; адаптив в ките не реализован,
  правила перехода описаны в `readme.md` и в карточках группы Type.
