Основная кнопка бренда — обводка 1px greige, без заливки и скруглений; на hover инвертируется в заливку greige с тёмным текстом. Одна кнопка на экран.

```jsx
<Button onClick={open}>Оставить заявку</Button>
<Button size="lg">Оставить заявку</Button>
```

- `size`: `md` (17px 34px) — стандарт; `lg` (19px 38px) — только финальный CTA на Terra.
- Текст всегда капителью, трекинг 1.5px.
- Кнопка не бывает залитой в состоянии rest и не бывает терракотовой: терракота в системе только для нумерации, меток и hover-ссылок.
