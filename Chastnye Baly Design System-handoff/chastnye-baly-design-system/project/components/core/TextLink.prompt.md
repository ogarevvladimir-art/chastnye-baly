Текстовая ссылка — антиква строчными, стрелка слева, подчёркивание, которое на hover дорастает до 100% ширины. Вторичное действие рядом с кнопкой или в тексте секции.

```jsx
<TextLink onClick={scrollToForm}>обсудить вечер</TextLink>
```

- Всегда строчными и без точки: это реплика, а не заголовок.
- Кегль по умолчанию 34px; уменьшайте через `size` только внутри плотных блоков.
- `showArrow={false}` — редкий случай, для перечислений.
