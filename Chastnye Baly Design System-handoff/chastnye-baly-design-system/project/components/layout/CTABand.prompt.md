Финальная полоса страницы на Terra — метка, крупный заголовок капителью, кнопка размера lg справа по нижней линии.

```jsx
<CTABand number="05" label="СВЯЗАТЬСЯ" title={<>Расскажите<br />о вечере</>} onAction={openForm} />
```

- Заголовок ломается вручную на две строки; кнопка выравнивается по базовой линии последней строки.
- Единственная кнопка на экране. Terra здесь закрывает страницу, как Terra её открыла.
