Полоса-передышка между двумя Ink-секциями: короткая врезка курсивом и крупная фраза антиквой, обе по центру.

```jsx
<QuoteBand eyebrow="мы научились танцевать вальс">
  чтобы вечер стал тем,<br />что вспоминают годами
</QuoteBand>
```

- Переносы строк ставятся вручную: фраза должна ложиться в 2–3 строки.
- Одна такая полоса на страницу. Второй Ash-блок подряд ломает ритм поверхностей.
