Шапка сайта — словесный знак слева, навигация по центру, телефон справа. Прозрачная поверх hero, при скролле заливается Ink.

```jsx
<SiteHeader
  items={['Как это происходит', 'Вечера', 'О нас', 'Связаться']}
  active="Вечера"
  phone="+7 495 000-00-00"
  surface="brand"
  onNavigate={setScreen}
/>
```

- Пункты капителью, 12px, трекинг 0.9px; неактивные — 50% (65% поверх Terra).
- Кнопки в шапке нет: целевое действие живёт в hero и в финальной полосе.
