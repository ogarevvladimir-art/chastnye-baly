# ORE — Дизайн-система

**Версия:** v0.1 — черновик
**Источник:** ore.co + отчёт ORE‑2026‑0811 (design critique)
**Дата:** 11 августа 2026
**Статус:** на утверждение design lead

> Токены, компоненты и паттерны, реконструированные из живого сайта ore.co и достроенные по находкам ревью. Спецификация, не код — для передачи в разработку и последующих съёмок/маркетинга.
>
> Пометки `existing` — извлечено из живого CSS/HTML сайта. Пометки `proposed` — новое, закрывает разрыв, найденный при аудите, обосновано в §10 Decision Trace.

---

## §1 Objective

**Что это:** формализованный язык дизайна ORE — атeлье bespoke-ювелирки (Bridal / Custom / Sourcing).

**Зачем:** сайт уже несёт сильную, но частично незадокументированную систему (два шрифта, узкая палитра, пронумерованная шкала кегля) — без спецификации она держится на памяти одного человека и рассыпается на краях, как в случае карточки Bridal.

**Для кого:** следующий разработчик, фотограф или маркетолог, который добавляет страницу, кадр или e-mail-рассылку и должен не «угадывать» стиль, а свериться с документом.

**Success metric:** новая карточка, страница или кампания проходит Anti-Pattern чек (§8) без правок и не создаёт второй такой находки, как Bridal.

---

## §2 Аудит

Источник — ревью ORE‑2026‑0811: разобран исходный HTML/CSS живого сайта (Nuxt + Contentful), а не догадка по скриншоту.

**Уже есть в системе:**
- Две гарнитуры на весь сайт — Chapman‑RegularCondensed (display) и AntarcticaVAR‑Regular (body/nav)
- Пронумерованная адаптивная шкала кегля (классы t5…t19, с `-md`/`-xl` вариантами)
- Узкая, дисциплинированная цветовая база — чёрный/белый/greige
- Reveal‑анимация на scroll (`data-preset="opacity,x"`, постадийные delay)
- Расширенный spacing‑модуль поверх Bootstrap‑утилит (`mb-7` и выше)

**Не задокументировано / отсутствует:**
- Ни одного interactive/focus‑токена — вся палитра статична
- Нет правила «фон карточки только тёмный» — отсюда разрыв в Bridal
- Нет постоянной точки контакта в хедере
- Нет описанной иерархии CTA (какой один — главный)
- Мёртвый Bootstrap‑слой в сборке — палитра, которой никто не пользуется

### Типографика — реконструированная шкала (existing)

В разметке уже используется пронумерованная responsive-шкала (t5…t19, с `-md`/`-xl` вариантами). Нумерация обратная — меньший номер соответствует более крупному кеглю.

| Токен | Роль | ~Кегль (desktop) |
|---|---|---|
| t5‑xl | Display / H1 | ~84px |
| t9–t10 | H2 («Bespoke Diamond Jewelry») | ~48px |
| t11–t12 | Eyebrow / Section («Our Work») | ~26px, uppercase, tracking .06em |
| body | Body copy | 17px / 1.6 |
| t16–t19 | Label / Nav («Bridal · Custom · Sourcing») | 14–15px |
| data | Fact/stat («12.011», «3.3 млрд лет») | 15px, mono, tabular-nums |

**Гарнитуры:**
- Display — `Chapman-RegularCondensed` (existing)
- Body / Nav — `AntarcticaVAR-Regular` (existing)
- Data / mono — не задан явно, рекомендуется системный моно-стек с tabular-nums (proposed)

### Spacing (формализовано из existing)

Классы вида `mb-7` в разметке показывают, что модуль уже расширен за пределы стандартного Bootstrap (0–5). Формализация в 8px‑сетке:

```
--space-2:  8px
--space-4:  16px
--space-6:  32px   /* между элементами компонента */
--space-7:  48px   /* mb-7, между компонентами */
--space-9:  96px   /* между секциями */
--space-10: 128px  /* hero, вступление секции */
```

### Radius, Elevation, Motion

| Токен | Значение | Правило |
|---|---|---|
| `--radius` | `0` | Везде, без исключений, кроме `--radius-circle: 50%` для play‑иконки видео |
| `--shadow` | `none` | Разделение — контрастом фото и hairline‑линией, не тенью |
| `--duration-reveal` | `700ms` (existing) | Fade + translateX(50px→0) при появлении в viewport |
| `--delay-step` | `100ms` (existing) | Шаг stagger между соседними элементами одной группы |
| `--ease-reveal` | `cubic-bezier(.16,1,.3,1)` (proposed) | Формализация кривой — в исходнике easing не задан явно |

## §4 Компоненты

### Persistent Header — новый

- **Purpose:** дать посетителю ровно один всегда доступный путь к контакту, не конкурируя с погружением hero.
- **Anatomy:** логотип (слева) + один текстовый CTA «Book a Consultation» (справа).
- **Variants:** transparent (поверх hero) · solid (surface-void 92% + blur, после скролла)
- **States:** default · hover (подчёркивание раскрывается слева направо, цвет → interactive) · focus (кольцо interactive-tint)
- **Tokens:** `--nav-height: 88px`, `--nav-cta: var(--interactive)`
- **Behavior:** fixed top; переход transparent→solid плавный, 300ms, по достижении конца hero.
- **A11y:** настоящая `<a href>`, не `<div onclick>`; видимый focus‑ring; skip‑link перед хедером.

### Category Card — фикс существующего

- **Purpose:** три равнозначных входа в коллекции — Bridal / Custom / Sourcing.
- **Anatomy:** full‑bleed фото + нижний scrim + подпись + arrow.svg.
- **Variants:** нет вариантов намеренно — три карточки идентичны по структуре, это и сообщает их равноценность.
- **States:** default · hover (image scale 1.03, arrow +4px, 300ms)
- **Tokens:** `--card-media-bg: var(--surface-void)` — **обязателен, без исключений**
- **Правило:** любой новый кадр для карточки — только в холодной ч/б студийной тональности Custom/Sourcing. Тёплые/цветные фоны (включая greige‑500) запрещены как фон на всю карточку — прямой фикс Находки 02.

### Arrow CTA / Text Link — existing

- **Purpose:** единственный стиль призыва к действию на сайте — сознательно без filled‑button варианта (анти‑паттерн U6).
- **Anatomy:** uppercase‑лейбл (tracking .05em) + arrow.svg.
- **Variants:** static (contact us) · slider (arrow‑small, без текста)
- **States:** default · hover (arrow translateX 6px, 200ms) · focus
- **Правило:** filled‑button не вводится вообще — если на экране нужен второй CTA, он текстовый и визуально тише первого.

### Fact / Stat Callout — existing

- **Purpose:** нести нарратив редкости через конкретику (атомный вес, возраст, глубина) — механизм, который держит копирайт вне антипаттерна «бессмысленный копирайт».
- **Anatomy:** крупная цифра (mono, tabular‑nums) + короткая подпись‑контекст.
- **Tokens:** `--text-data`, `font-variant-numeric: tabular-nums`
- **Правило:** каждый новый факт — проверяемый и специфичный для алмазов/бренда, не общее «удивительный факт».

### Portfolio Slider «Our Work» — existing

- **Purpose:** показать узкую, кураторскую подборку работ в темпе атeлье, не каталога.
- **Anatomy:** одно крупное фото + счётчик «01/05» (mono, tabular) + мелкие prev/next.
- **Правило:** каждый слайд обязан держать ту же чёрную студийную постановку, что и hero — иначе концепция размывается к середине страницы.

### Footer Story Block — existing

- **Purpose:** закрыть страницу нарративом бренда + единственным на всю домашнюю страницу явным «contact us».
- **Anatomy:** крупная display‑цитата + текст + arrow‑CTA + завершающий fact-callout.
- **Связанная находка:** сейчас это единственный вход в контакт — Navigation Pattern (§5) предлагает не убирать этот блок, а дублировать путь в хедере.

## §5 Паттерны

**Navigation — минимальный, но не спрятанный.** Три маршрута (Bridal/Custom/Sourcing) остаются на своих местах в скролле. Добавляется не полноценное меню, а один постоянный элемент — Persistent Header CTA (§4). About/Story остаются частью повествования, но получают якорную ссылку в футере, чтобы быть находимыми без полного скролла.

**Card‑grid — 3‑up, не 4.** Сетка не растягивается до «круглого» числа искусственным четвёртым пунктом — три карточки отражают реальные три направления бизнеса. Добавление четвёртой ради симметрии — нарушение §8.

**Reveal‑on‑scroll — единственная анимация системы.** opacity 0→1 + translateX/Y 50px→0, stagger `--delay-step` между соседними элементами одной группы. Никаких других видов motion (parallax, авто‑play каруселей, decorative loops) — единообразие движения так же важно, как единообразие цвета.

---

## §6 Voice & Tone

**Тон:** сдержанный, мифологизирующий, точный.
**Лексика:** «unattainable», «diamantaires», геологические факты — не использует «premium quality» без конкретики за ним.
**Длина предложений:** короткие декларативные + один развёрнутый факт для контраста.
**Юмор:** отсутствует — не тот регистр.

---

## §7 Accessibility Baseline

| Требование | Значение |
|---|---|
| Контраст текста | white / gray-1000 ≥ 15:1 · gray-400 на gray-1000 ≥ 4.6:1 |
| Focus | видимое кольцо `--interactive-tint`, включая arrow‑CTA и слайдер |
| Motion | `prefers-reduced-motion` отключает translateX/Y, оставляет только opacity |
| Alt‑текст | каждое фото — описательный alt, не имя файла |

---

## §8 Anti-Patterns — специфично для ORE

1. Тёплый/цветной фон на всю карточку продукта — только чёрно‑серая студийная тональность (см. greige‑500, §3).
2. Больше одного filled‑button CTA на экране одновременно — в системе filled‑кнопки нет вообще.
3. `border-radius` отличный от 0 — ломает архитектурную строгость бренда.
4. Новый компонент без reveal‑анимации при первом появлении — единообразие движения обязательно.
5. Пункт в навигации сверх Bridal/Custom/Sourcing/Contact — бренд bespoke, не каталог; каждый лишний пункт размывает эксклюзивность.
6. Деплой без прогона og:/twitter: метатегов через валидатор — источник Находки 01 в ревью.

## §9 Governance

Бренд компактный — комитет не нужен, но точка ответственности должна быть одна, не «кто успел».

| Роль | Отвечает за |
|---|---|
| Design lead | Новые токены, компоненты, финальное «да» на любой кадр вне текущей тональности |
| Разработчик | Соответствие токенам в коде, чистка мёртвого CSS (Bootstrap‑слой) при каждом релизе |
| Фотограф/стилист | Соблюдение студийной постановки (свет, чёрный фон, реквизит) для новых кадров |

Новый компонент добавляется только через формат спецификации §4 (Purpose → Anatomy → Variants → States → Tokens → Behavior → A11y). Deprecated‑компонент — с указанием замены и окном миграции 2–4 недели.

## §10 Decision Trace

### Decision 1 — accent-gold как единственный interactive-токен
```json
{
  "decision": "Ввести accent-gold-600 (#B08D3D) как единственный цвет для hover/focus/active",
  "reason": "У чёрно-бело-greige системы не было ни одного цвета для интерактивных состояний — они были визуально неотличимы от статики",
  "alternatives": ["Подчёркивание без цвета", "Генерический синий focus-ring"],
  "tradeoff": "Вводит единственный «цветной» акцент в монохромный бренд — риск, что его станут использовать не только для интерактива. Правило: только hover/focus/active, никогда — заливка или декоративный элемент."
}
```

### Decision 2 — card-media-bg заблокирован на surface-void
```json
{
  "decision": "Зафиксировать фон медиа-карточки на surface-void (gray-1000) без исключений",
  "reason": "Найден вероятный источник Находки 02: существующий токен greige-500 (#A84F2D), применённый как фон целой карточки вместо точечного акцента",
  "alternatives": ["Оставить выбор фона на усмотрение каждой съёмки — статус-кво, который и привёл к разрыву"],
  "tradeoff": "Меньше творческой свободы для будущих стилистов Bridal-линии; компенсируется тем, что greige-палитра остаётся доступна как акцент внутри кадра (кожа, дерево), просто не как фон на 100% площади"
}
```

### Decision 3 — radius: 0 повсеместно
```json
{
  "decision": "Зафиксировать --radius: 0 для всех элементов, кроме --radius-circle: 50% на play-иконке",
  "reason": "Ни один существующий элемент (карточки, кнопки, изображения) не использует скругление — это уже де-факто конвенция бренда, документ лишь фиксирует её",
  "alternatives": ["Небольшой radius 4–8px для «мягкости»"],
  "tradeoff": "Менее «дружелюбно» на первый взгляд, но соответствует позиционированию точности и геммологической строгости, которое уже несёт остальная система"
}
```
