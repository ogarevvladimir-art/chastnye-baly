# Частные балы — сайт

Лендинг услуги «Частные и корпоративные балы» (Plyaskin Group, СПб, с 2009 года).

## Структура

| Папка | Что внутри |
|---|---|
| `Прототип/` | Рабочий прототип: `index.html`, `styles.css`, `script.js` + фотографии |
| `Макет/` | Референсы, дизайн-система ORE, тексты блоков, токены Tilda |
| `Макет/референс/` | Скриншоты ore.co — основной визуальный ориентир |
| `Тескт Частные балы/` | Тексты страниц в Markdown |
| `Частные балы/` | Исходные материалы: структура сайта, ЦА, этикет, дресс-код |
| `Шрифты/` | Old Standard TT и Inter Tight (OFL) |
| `assets/` | Общие фотографии проекта |

## Прототип

Открывается напрямую — сборка не нужна:

```
Прототип/index.html
```

Внешние зависимости подключены с CDN: GSAP 3.12.5 (+ CustomEase, ScrollTrigger), Lenis 1.1.18, шрифты Google Fonts (Manrope, Old Standard TT).

### Дизайн-система

Токены в `Прототип/styles.css`, секция «1. ТОКЕНЫ». Палитра, типографика и spacing реконструированы из `Макет/ORE — дизайн-система.md` и `Макет/chastnyebalystyles.json`.

Ключевые принципы:

- `--radius: 0` везде, без исключений
- Единственный стиль CTA — текстовая ссылка со стрелкой, filled-кнопок в системе нет
- Разделение — контрастом и hairline-линией, не тенью
- Всё, что движется, отключается при `prefers-reduced-motion`

## Чего нет в репозитории

Исключено через `.gitignore`:

- **Видео** (`*.mp4`) — превышают лимит GitHub в 100 МБ на файл. `Прототип/assets/hero.mp4` нужен для фона первого экрана, хранится локально
- **Коммерческие шрифты** — Akkurat и Thunder, лицензии не допускают распространения
- **Архивы и исходники** — `*.zip`, `*.psd`, `*.skp`, `*.fig`

## Статус

Прототип главной страницы. Реализовано: асимметричная сетка со служебной полосой, схемы танцев с прочерчиванием, sticky-стопка в разделе «Люди», инерционный скролл, раскрытие медиа маской.

В работе — сближение с референсом ORE: гигантская типографика во всю ширину, диагональ микротекста, разведённые цветовые сцены.
