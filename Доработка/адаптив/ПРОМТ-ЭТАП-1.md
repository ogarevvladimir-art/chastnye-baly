## Порядок: три части, по одной

Для каждой части — цикл из ОБЩЕЕ «Порядок работы по блоку»: рендер десктопа → предложение
**Сейчас → Что не работает на телефоне (с цифрами) → A / B → D → рекомендация → где лягут кадры** →
мой выбор → **один кадр покоя 390** → моё «да» → состояния, раскадровка, прототип → рендер ×1 и ×2 → ЖУРНАЛ.
Развилки задавай через AskUserQuestion. Прежде чем собирать все состояния смелого варианта, покажи один кадр.

### 1. Hero → Форматы (сверху — закрытая шапка)

Десктоп: Hero `223:2150` (покой) / `223:2222` (C·2); Форматы `223:2169` покой, `223:2185` «Частные»,
`223:2203` «Корпоративные»; заметка для разработки `223:2260` — прочитай её, там логика шва.

Что решить (цифры проверены):
- **«БАЛЫ»** стилем `v2/M/Display/Giant XL` 91 = 347 px из 358 — входит. На сайте ниже 390 — 23,3vw
  (на 360 это 84 = 320 px из 328).
- **Шов.** На десктопе «БАЛЫ» — один sticky-элемент через шов. У ore на телефоне закреплений нет:
  гигант собирается из растянутых букв по входу. Варианты для A/B: короткое закрепление через шов
  (≤ 150svh; одно из двух допустимых на страницу, второе оставлено за 02 Вечер) — или без закрепления,
  «БАЛЫ» собирается по входу и в hero, и на шве. Рекомендацию обоснуй правилами ОБЩЕЕ и лимитом закреплений.
- **Половины «частные» / «корпоративные».** По 195 px фото слишком узкие, наведения нет. Варианты: два экрана
  подряд; свайп между половинами (`set_overflow` HORIZONTAL или ON_DRAG); переключение тапом. Ссылки
  «Обсудить … бал →» — в единственном числе (решение пользователя), множественное — только в названиях.
- **Подпись hero.** «Ваша история.» / «Ваш вечер.» — `v2/M/Display/H2` 52 лесенкой, вторая строка прижата
  к правому краю; ссылка под ней; «ЧАСТНЫЕ» меткой над «БАЛЫ».
- **Фото bg-1** (1920 × 1080) в портретном кадре 390 × 844 берёт ≈ 500 px ширины исходника. На экране 3× это
  растяжение ≈ 2,3 раза. В Figma кадрируй осознанно (арки, люстры), в ЖУРНАЛ — флаг: сайту нужен вертикальный исходник.

### 2. Шапка и меню

Десктоп: инстанс `Header · v2` (мастер `180:1505`); меню `219:1444` закрыто, `219:1067` открыто · покой,
наведения 01–12 `219:1096` + 29·k. Слова и метки бери из десктопных кадров меню, не придумывай.

- **Шапка:** логотип слева, «Меню» капсом справа (у ore «MENU» ≈ 13), зона нажатия ≥ 44 × 44, фиксирована
  при скролле (`pin_child` или `set_fixed_children`). Делать ли мобильную шапку вариантом компонента
  `Header · v2` — предложи, но исходный мастер без моего «да» не меняй.
- **Меню у ore** (ОБЩЕЕ → «Меню»): шторка Ink сверху ≈ 0,7 с, пункты гигантом стопкой у нижнего края,
  цвета пунктов чередуются, «MENU» ↔ «CLOSE» перебором букв, тап — сразу переход, закрытие ≈ 0,45 с.
- **Развилка по кеглю** (Unbounded Bold, −3 %): в `v2/M/Display/Giant` 45 **ПОДГОТОВКА = 397 px — не входит**
  (входит при ≤ 40,5); АССИСТЕНТ 353 — впритык; остальные 10 входят. Стопка 12 строк при 45 × 85 % ≈ 460 px —
  под шапкой в 844 входит. Варианты: все 12 слов одним кеглем ≈ 40 (одна роль — один кегль, порог 38 соблюдён,
  но это отступление от шкалы); логика десктопа — список меток капсом плюс одно гигантское слово раздела,
  где сейчас читатель; Giant 45 с переносом «ПОДГО- / ТОВКА». Кегль под каждое слово не подгонять.
  Если нужен кегль вне шкалы `v2/M/…` — это решение с моим «да», и оно записывается в таблицу ролей.
- **Цвета пунктов** — чередование Greige Light / Terracotta Deep по образцу ore.
- **Меню — полноэкранный кадр 390 × 844**, не оверлей: позицию и затемнение оверлея через MCP не настроить.
  Переход — NAVIGATE + Smart Animate. «Меню» ↔ «Закрыть» и шторка — раскадровкой по времени и в заметке.

## Раскадровка и заметка — формат, который утверждаем на пилоте

- **Анимация входа по времени** (сборка гиганта: каждая буква `scaleX 3` → 1 со сдвигом, ≈ 1,3 с на слово,
  expo-out; проявление антиквы ≈ 0,8 с): три кадра **0 / 50 / 100 % времени**, имя `… · вход 0 % / 50 % / 100 %`.
- **Закрепление** (если выберем): три кадра **0 / 50 / 100 % прохода**, имя `… · скролл 0 % / 50 % / 100 %`.
- **Заметка для разработки** — в конце строки, ширина 1440, по образцу десктопных заметок (`223:2260`):
  триггер (верх элемента на 90 % экрана, один раз), длительность, кривая, свойства (только transform,
  opacity, clip-path), `prefers-reduced-motion` → статичный кадр покоя, `svh` / `dvh`, длина закрепления.
- После моего «да» добавь в ОБЩЕЕ раздел **«Приёмы пилота»**: формат раскадровки и заметки, шапка, меню,
  анимация входа. Дальше этапы идут по нему.

## Правила

- Не трогать `191:626`, всё внутри `225:864` «Frame 5», доску системы этапа 0 и существующие стили
  и переменные. Мобильные кадры — клоны десктопных, перестроенные.
- Кегли — только стилями `v2/M/…` (ID в ОБЩЕЕ → «Стили»); текст цветом Ink — `S:60c344a8…`, не `S:c0cc7d15…`
  (это фон). Трекинг только в процентах. Мелкий текст на Terra / Ash — Greige Light.
- Копирайт не менять; противоречия — флаг в ЖУРНАЛ.
- Язык ore: два полюса без середины, одно слово одной роли — один кегль, длинное — переносом лесенкой,
  никаких схем, выносок, центрированных абзацев. По умолчанию рекомендуй ближайший перенос десктопа,
  смелую перестройку — альтернативой.
- Отвечай по-русски, коротко поясняй ход на ключевых шагах. Этап 2 не начинай.
