# Блоки: что на десктопе и что делать на телефоне

ID — по состоянию на 2026-09-29, всё внутри `225:864` «Frame 5». «Покой» лежит в `191:626`,
состояния — рядом во Frame 5. Направления для телефона — **черновик**: на этапе блок проходит
обычный цикл «Сейчас → Что не работает → A / B → D → рекомендация», выбирает пользователь.
Кегли «входит при …» — Unbounded Bold в 358 px (390) / 328 px (360), посчитаны по шрифту.

## Шапка и меню (этап 1)

- **Десктоп:** инстанс `Header · v2` (мастер `180:1505`); меню — `219:1444` закрыто, `219:1067` открыто · покой,
  наведения 01–12 `219:1096` + 29·k. На наведении — гигантское слово раздела Terracotta Deep 150.
- **На телефоне ломается:** наведения нет, 12 меток в две колонки не помещаются. Самые длинные слова раздела:
  ПОДГОТОВКА входит при 39 / 36, АССИСТЕНТ 44, ДРЕСС-КОД 46, СВЯЗАТЬСЯ 45.
- **Черновик:** логотип слева, «Меню» капсом справа (как MENU у ore), шапка фиксирована при скролле.
  Открытое меню на весь экран: метки одной колонкой, гигантское слово — у раздела, в котором сейчас находится
  читатель (вместо наведения), или по тапу, до перехода.
- **После этапа 0:** меню ore снято (ОБЩЕЕ → «Меню»): шторка Ink сверху ≈ 0,7 с, пункты гигантом стопкой
  у нижнего края, «MENU» ↔ «CLOSE» перебором букв, тап — сразу переход. Замер Giant 45 (−3 %): ПОДГОТОВКА
  397 px — **не входит** (входит при ≤ 40,5), АССИСТЕНТ 353 — впритык, остальные входят; стопка 12 строк
  ≈ 460 px — в 844 входит. Меню и форма — полноэкранные кадры 390 × 844: оверлей через MCP не настраивается.

## Hero → Форматы · стык «Балы перетекают» (этап 1)

- **Десктоп:** Hero `223:2150` (покой) / `223:2222` (C·2); Форматы `223:2169` покой, `223:2185` наведение «Частные»,
  `223:2203` «Корпоративные»; заметка `223:2260`. «БАЛЫ» 344 от оси 64 — один sticky-элемент через шов,
  наведение раздвигает половины. «Ваша история.» от 64 / «Ваш вечер.» от 720, ссылка на оси.
- **На телефоне ломается:** наведение раздвигает половины; две половины по 195 — фото слишком узкие.
- **Входит:** БАЛЫ 91 / 83 — гигант во всю ширину с запасом. «корпоративные» антиквой — 53.
- **Черновик:** «БАЛЫ» 91 во всю ширину закреплено при скролле и переезжает через шов (раскадровка). Половины
  «частные» / «корпоративные» становятся двумя экранами подряд; второе фото раскрывается от оси по скроллу.
  «Ваш вечер.» — вторая строка лесенкой к правому краю.
- **После этапа 0:** у ore на телефоне нет закреплений и скраба — гигант собирается из растянутых букв
  по входу (≈ 1,3 с). Закрепление «БАЛЫ» через шов — наш ход, одно из двух на страницу (второе — 02 Вечер).
  Альтернатива без закрепления — «БАЛЫ» собирается по входу и в hero, и на шве. Фото bg-1 (1920 × 1080)
  в портретном кадре 390 × 844 берёт ≈ 500 px ширины исходника — на экране 3× растянуто ≈ 2,3 раза: флаг для сайта.

  Для ВОСПОМИНАНИЯ — ход из ОБЩЕЕ: перенос «ВОСПОМИ- / НАНИЯ» лесенкой (≈ 45 для всех строк, на 360 тоже) или

## 02 Вечер · часы (этап 2)

- **Десктоп:** `223:2466` 18:00, `223:2492` 19:00, `223:2518` 19:20, `223:2544` 21:50, `223:2570` 22:20;
  заметка `223:2463`. Часы антиквой 224, фото 800 × 960, «Партитура» — отрезки по длительности и интенсивности.
  На сайте — закрепление экрана при скролле.
- **На телефоне ломается:** три колонки (часы / партитура / фото) в 390 не встают.
- **Входит:** «22:20» антиквой — 138, значит 120 с запасом.
- **Черновик:** экран закреплён; часы сверху меняются как счётчик, фото под ними, партитура — полоса прогресса
  по нижнему краю. Раскадровка 5 кадров вместо 3. Закрепление ≤ 150svh — иначе пять шагов делятся на
  отдельные экраны без закрепления.

## 05 Шоу · «Занавес» (этап 3)

- **Десктоп:** `213:778` Профессионалы, `213:872` Совместный, `213:899` Номер от своих; заметка `213:937`.
  Сцена 1440 × 900, занавес раскрывается от оси; название формата Unbounded Bold 107 в «барабане» на нижнем

  по скроллу или перенос лесенкой, выбрать в A/B.
- **После этапа 2:** переносы в гигантах запрещены. Прецедент 01 — все слова роли вертикально. Грубый замер
