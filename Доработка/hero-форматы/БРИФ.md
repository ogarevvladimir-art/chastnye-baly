## Грабли инструмента

- `create_text` со стилем требует явных fontFamily/fontStyle, а явный шрифт отвязывает стиль: после создания повторить `set_text textStyleId`.
- textCase UPPER / override fontSize отвязывают стиль. `set_text_range` (курсив) — после `apply_style_to_node`.
- `resize_nodes` по тексту фиксирует высоту, потом снова `textAutoResize HEIGHT`. Всегда передавать обе стороны.
- RIGHT-выключка + resize сдвигают x: после resize ставить `move_nodes`.
- Клон кадра с потомками: ID детей = ID клона + константа.
- CROP-фото (`197:1229` в Форматах) — заливку не перезаписывать, кадрирование сбросится. Клон кладётся в обрезающую рамку.
- Масок в batch нет: окно в буквах только через boolean SUBTRACT → FLATTEN (так сделан hero B).
- `set_opacity` берёт `nodeIds` на уровне op. `rename_node` — только первый id, для нескольких нужен `map`.
