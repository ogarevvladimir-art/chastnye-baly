# Site edits log

Remarks collected after reviewing the site with animations (from 2026-10-03). Procedure:

1. The user sends one remark at a time in chat — a description and screenshots.
2. Claude analyses it: finds the place in code and design, names the cause, asks questions. An entry goes into this file
   only after the user confirms.
3. When the user says there are no more edits, Claude organises the list (groups, duplicates, dependencies,
   priorities), asks questions and after the answers writes the change plan.

While collecting, code in `site/` doesn't change.

The user puts screenshots in `Доработка/Скрины правок/` («Правка N.jpg»); the entry links to the file.
User quotes stay in Russian, with an English gloss.

## Entry template

```
### П-NN · <block> · <widths / device>
- Remark: in the user's own words
- Now: what the site shows and why (selector, file, stage decision or design)
- Should be: what the user confirmed
- Type: build bug / mismatch with design / design change / animation / copy / behaviour
- Affects: files and blocks; whether Figma needs editing
- Screenshots: Доработка/Скрины правок/Правка N.jpg
- Questions: open ones (if any)
```
