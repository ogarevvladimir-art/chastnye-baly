# Chastnye Baly build techniques

Moved out of `ОБЩЕЕ.md` on 2026-10-07. Standing code rules by stage: each section adds to the previous ones; "don't change further" means don't change.
Read when building or fixing a block; not needed for decisions, reviews or Figma work.

## Pilot techniques (stage 2, 2026-10-03) — don't change further

- **Block coordinates come from the Figma frame, multiplied by `--u`.** Phone and tablet — flow (grid / flex) with offsets from the frame (`calc(N * var(--u))`);
  desktop — the 1440 composition: point x → `calc(var(--x0) + (x − 64) * var(--u))`, y → `y * var(--u)`. Above 1920 everything is centred via `--edge`.
- **Desktop states** (hovers, clicks) — `data-state` on the section; everything that changes is `transform`, `opacity`, `clip-path` taken from the state-frame
  coordinates, 0.35 s `--ease-state`. Mouse — `pointerenter`, keyboard — `focusin` inside the part, touch on a wide screen — tap. Links hidden
  at rest stay focusable (opacity, not visibility).
- **Parts that expand** (halves, panels) — full-width layers with `clip-path: inset()`: hit-testing follows the clip-path, so the hover
  boundary moves by itself.
- **Entrances — `motion.js`, attributes in the markup:** `data-giant` (assembly, (n+1) × 1em, 0.15 + 0.05n s, 0.8 s expo-out), `data-reveal="text"` / `"fade"`,
  `data-photo` (img scale 1.1 → 1), `data-reveal="bar"` (scaleX 0 → 1), `data-delay`. A vertical giant — the same `data-giant` on an element with
  `writing-mode: vertical-rl; transform: rotate(180deg)` (stage 3: the word takes space in the flow; `motion.js` switches to translateY / scaleY itself). Start
  states — `motion.css` under `html.js:not(.no-motion)` and `prefers-reduced-motion: no-preference`.
- **Shading and «Тон» (tone) — block CSS gradients**; the profile is obtained by fitting the Figma render to the file from `site/img/` (`tools/overlay_profile.py`
  and the colour fit in the stage 2 journal): the plugin doesn't return gradient stops. The «Тон» colour is the part's surface (`--surf-rgb`), not Ink.
- **A photo whose file is wider than its window** (headroom for states): window `overflow: hidden`, `<picture>` inside with offset and file size in `--u`;
  where a stage 1 crop was overridden, find the file position by matching the Figma window against the file (OpenCV `matchTemplate`), not via `photos_site.json`.
- **Link tap area** — the link itself spans the column row with `padding-block: 8px` and compensating margins, no pseudo-elements
  (a pseudo-element wider than the column causes horizontal scroll at 360).
- **Block comparison:** `tools/pilot_shots.py` as the model — site frames in a window the height of the Figma frame (desktop 1440 × 932), lazy photos preloaded,
  storyboard — `document.getAnimations()` paused at 0 / 25 / 100 %; behaviour — an autotest modelled on `tools/pilot_check.py` in chromium and webkit.
- **Fonts — static cuts only** (Unbounded 400 / 700): WebKit on Windows ignores variable-font axes.

## Stage 3 techniques (2026-10-03) — add to the pilot

- **Section header — `.sh`:** label (`.t-label.t-accent`), H2 from `.sh__l1` / `.sh__l2`, lead `.sh__lead`. Second line: phone — to the right edge;
  tablet — `.sh--l2-axis` (from the axis) or `.sh--l2-right`; desktop — from the axis or `style="--l2x: N"` (design point − 64). Desktop lead width — `--lead-w`
  (default 416px), colour — `--lead-d` (default Greige 80). Entrances: label fade 0.15, H2 lines 0.3 / 0.4, lead 0.5 s.
- **Small accent — `.t-accent`:** Terracotta only on Ink; on Terra / Slate / Ash — Greige Light (user decision, all widths).
- **Counters — «01 / 05»** (label 11, tracking +40 %) at all widths.
- **Desktop states — `js/states.js` `hoverStates(section, parts, {key, rest, keep, click})`**: `data-state` on the section, `data-on` on the part,
  `tabindex` on parts only on desktop. No rest state — `rest: null` (03); don't reset when the cursor leaves — `keep`.
- **Full-bleed strips on desktop — `--su`** (window up to 1920 / 1440); columns and margins — `--u`. A full-bleed element above 1920 — `margin-inline: var(--edge)`
  or `right: var(--edge)`.
- **Small-text columns on desktop — in px** (416 etc.), on phone and tablet — `N × --u`. If a px column may overflow at 1024 —
  `minmax(0, 416px)` / `min(416px, 416 × su)`.
- **Without JS** content hidden at rest (01 descriptions, 04 paragraphs, 02 pinning) is visible: hiding rules sit under `.js`.
- **Pinning with step change (02):** track = scene + (steps − 1) × `--D`, the scene is `sticky`, step = nearest position (`blocks.js`); the model for
  other pinned scenes.
- **Photos — `tools/picture.py`** (markup from `photos_site.json`; a layout without a photo gets an empty GIF). Copy — only from `ТЕКСТ.md` without «*из …*» notes.
- **Block comparison:** `tools/stage3_shots.py` (rest — in a window the height of the section, hovers — in a window taller than the section, no scrolling) and `tools/stage3_check.py`.
  Before `reload` in tests — `history.scrollRestoration = 'manual'`, otherwise the entrance starts before the storyboard pause.

## Stage 4 techniques (2026-10-03) — add to the pilot and stage 3

- **"One of N" switcher — `js/switch.js`:** `createSwitch` (cyclic step), `setPositions` (`data-pos` before / active / after on layers with `data-i` —
  curtain, drum and frame changes are drawn in CSS by `data-pos`), `tabs` (role="tab", arrows, roving tabindex), `swipe` (≥ 40 px, touch only,
  `touch-action: pan-y` on the zone), `scrollSteps` (steps of a pinned scene by scroll, and scrolling to a step). 05 is the model for 10.
- **Change "without overlap" — one attribute:** inactive — opacity 0, +16, `visibility: hidden` after 0.2 s; active — delayed 0.2 s, over 0.3 s.
  Both roles in one grid cell (`grid-area: 1 / 1`) — height of the longer one; a repeated tap during a change is ignored.
- **«Над светлым» (over light) header — per part:** the light zone is an element with `data-header="light"` (a panel, not a section); only the header part
  under whose middle the zone lies turns dark (`data-over="light"`).
- **Entrances:** `data-rise="24"` — rise while revealing; an element that has `data-in` set before `initMotion` gets no entrance (words of hidden formats).
- **Vertical writing in an absolute layer:** set the layer height and line length explicitly (`height: N × u`, `inline-size: max-content`) — WebKit computes them
  from the browser window. Horizontal giants with an entrance — `overflow-x: clip` on the line.
- **Comparison:** `tools/stage4_shots.py` (mid-change states — a click and all section transitions paused), `tools/stage4_check.py` (swipe — synthetic PointerEvents
  with `pointerType: 'touch'`).

## Stage 5 techniques (2026-10-03) — add to the pilot and stages 3–4

- **Figure = photo frame** (09): the word, number and text column are positioned from it; marks on the photo («+») — in % of the frame, the same at all widths. Offset an element
  that has an entrance with the `translate` property (or `margin`), not `transform`: transform is taken by the entrance WAAPI.
- **"Always forward" change** (10): layers of the new step are placed in `after` without a transition (`data-jump`), then `active`; the previous one — `before`. For a cyclic switcher
  where the new frame always opens on top. While a change is running, a new one isn't accepted.
- **Auto-advance** (10, desktop): `setTimeout` 4 s, restarted after every change and click; pause — hover over block zones, focus inside, off-screen (IO 0.3),
  `document.hidden`, reduced-motion.
- **Form sheet — `js/form.js`:** all openers — `[data-form="field"]` (+ `data-format`), click delegation on the document; the menu with its own `data-form` items
  only closes. Keyboard focus styling for inputs — `html[data-kbd]`. Without JS and without `<dialog>` the sheet sits on the page.
- **Photo markup** — the marker `{{pic key | m="…" t="…" d="…" | alt}}` in the draft and `tools/fill_pictures.py`.
- **Comparison:** `tools/stage5_shots.py`, `tools/stage5_check.py`; check horizontal scroll also during entrances (scroll to the block −200 and measure after 250 ms).

## Rework Д1 techniques (2026-10-04) — add to stages 2–5

- **JS safety net:** `index.html` sets `js`, `main.js` — `window.__ready` (modules ran), `motion.js` — `window.__motion` (entrances started).
  Module load error — `onerror` → `__nojs()` (class `js` removed at once); otherwise after 3 s: no `__ready` — no-JS mode, no `__motion` — `no-motion`.
  Modules arrived late — `js` + `no-motion`. Every `init*` (and every block in `initBlocks`) — in its own `try / catch`.
- **Entrances wait only for giant fonts** (`document.fonts.load` with the style of `[data-giant]` elements), not `document.fonts.ready`.
- **`modulepreload` — desktop only** (`media="(min-width: 1024px)"`): on phone early modules take bandwidth from the hero photo (measured with `tools/lcp.py`).
- **Desktop menu below 932:** top of labels `min(144px, 15.45dvh)`, bottom of the giant `max(72px, min(100px, 10.73dvh))`, giant size — fits between
  labels and bottom (gap 24), no lower limit. Closing: giants hidden, the clicked item (`data-picked`) leaves with the curtain.
- **Form opener without a field** — focus on the sheet heading (`#form-h`, no outline): no on-screen keyboard.
- **Small text on Terra / Ash / Slate** — `var(--c-small, …)` on desktop too (leads `.sh__lead`, 04 tempo).
- **Full-page comparison** — `shots.py` stitches screens by shifting `body` (not `full_page`: capture outside the window loses photos).
- **Checks:** `tools/d1_check.py` (П-01, П-03, Р-2, Р-3, Р-8…Р-10, Р-14, 360), `tools/axe_check.py` (axe-core from `tools/node_modules`),
  `tools/lcp.py` (LCP without throttling and with CPU ×4 + 1.6 Mbit/s network).

## Rework Д2 techniques (2026-10-04) — the "fit to screen" system, don't change further

Approved by the user (variant B, Figma section `302:1492`, note `302:2175`). Rule П-04: **every desktop block is exactly one window**.

- **Desktop block = window:** `height: 100vh; height: 100svh`. The 72 header sits on top; the content top line is **104 px** (72 + 32).
- **Two units:** x and columns — × `--u` (as before); y, giants and serif display — × **`--s` = min(u, window height / 900)** (`tokens.css`, desktop only).
  Reference frame — **1440 × 900**: there s = u = 1 and Figma frame coordinates transfer as is. Anchoring to the block bottom — `calc(100% − N * var(--s))`.
- **Fixed (px):** small text (caps 12, Body 12, link 30), the 104 top line, offsets from part edges.
- **Shrink order on a low window:** the photo takes the remaining height (photo window from N·s to the bottom), giant and serif shrink by s, small text
  doesn't change. No lower limit, no scrolling inside the block.
- **Small text wraps instead of overlapping:** description column — `min(392px, 392 × window / 1440)`; a "number + text" line at rest is bottom-anchored
  (`translate(…, calc(Y − 100%))` — long text grows upward), on hover — top at the 104 line.
- **Р-15 — margins above 1440:** offset from a part edge (axis, half boundary, right page edge) — fixed 64 / 72 px, not × u.
- **Anything that depends on text height** (description length) is measured by JS into a variable (`--drop`, `--lw-p` / `--lw-c` in `hf.js`); the default value is in CSS.
- **Check windows** (browser viewport): 1440×900, 1920×950, 1366×650, 1280×600, 1024×650. Comparison — `tools/d2_compare.py` ("Figma | site" pairs
  and numbers against frame nodes, 4 px threshold); behaviour — the "Д2" section in `tools/pilot_check.py` (block = window, everything needed in the window, giant not over text,
  phone and tablet — flow).
- **Pitfalls:** WebKit ignores `flex-basis` when sizing an absolute flex container to content and squeezes neighbouring text — set `width`
  and `flex: none`. On low windows the photo window rises to the text — text layers `z-index: 1` above the photo.
- **Figma:** approved work is edited in the live frames (`191:626` uses auto-layout: block heights shift the page themselves), variants — a section under Frame 5.
  At 1440 × 900 s = 1: only frame heights and bottom-anchored y change.
