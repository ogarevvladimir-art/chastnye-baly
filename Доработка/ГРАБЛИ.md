# Грабли инструментов

Собрано из памяти Claude 2026-10-07 (сентябрь–октябрь 2026). Новые — дописывать в свой раздел.

## figma-mcp-express: связь и пачки

- Плагин отключается посреди сессии — проверять `list_channels`.
- «rpc transport failed» или оборванный ответ: прочитать узел — операции обычно применились. Пачки > ~80 операций обрывают ответ, но применяются — проверять последний узел.
- `batch` ≤ 2 МБ: картинки `import_image` — по несколько штук.
- Ссылки в пачке `$N.id` — N с нуля. `map`: `{type:"map", over:[…], as:"x", do:{…}}`, принимает литеральный массив id; enum (например, `textAlignHorizontal`) ссылкой в `map` не передать.

## Скриншоты

- `save_screenshots` пишет только внутрь рабочей папки `VS CODE/` (путь относительный, `.figma-shots/x.png`; `../` и scratchpad отклоняются).
- Не перезаписывает существующий файл — давать новое имя. Игнорирует scale. У скрытых узлов — пустой PNG.
- Дочерний узел внутри обрезающей рамки — PNG только видимой части, хотя в ответе размер узла.

## Параметры операций

- `set_text` — один `nodeId` в params и плоские `letterSpacingUnit` / `letterSpacingValue` / `lineHeightUnit` / `lineHeightValue`.
- `resize_nodes`, `set_opacity`, `reorder_nodes` — `nodeIds` на уровне операции. У `reorder_nodes` параметр `order`.
- Порядок слоёв: `bringForward` упирается в index 1 и в пачке не накапливается; два `bringToFront` в одной пачке дают один индекс. Надёжно — `sendToBack` по списку в обратном порядке или серия `bringToFront` по одному.
- `rename_node` переименовывает только первый из `nodeIds` — для нескольких `map`. `batch_rename_nodes` — только find/replace или prefix/suffix.
- `move_nodes` только двигает; смена родителя — `reparent_nodes` (для укладки в auto-layout `preserveAbsolutePosition: false`). Удаление — `delete_nodes`.
- `create_text` не принимает layoutSizing (размер — `resize_nodes` после). С `textStyleId` требует явных `fontFamily` / `fontStyle`, но явный шрифт отвязывает стиль — после создания повторить `set_text textStyleId`. `textAlignHorizontal: RIGHT` до resize сдвигает x — после resize `move_nodes`.
- `resize_nodes` по тексту фиксирует высоту → снова `set_text textAutoResize: HEIGHT`. На auto-layout-фрейме фиксирует высоту → `set_auto_layout primaryAxisSizingMode: AUTO`. `height: 0` обнуляет высоту — всегда передавать обе стороны. Паддингов у `resize_nodes` нет — только `set_auto_layout`.
- `set_reactions`: `delay: 0` обязателен, тайминги в мс. На тарифе пользователя нельзя двух действий в одной реакции; ON_DRAG не открывает оверлей.
- `NOISE` в `set_effects` — «not a function»: текстуры — PNG-тайлом (`import_image scaleMode: TILE`). Масок в batch нет — окно в буквах через boolean SUBTRACT → FLATTEN. `clipsContent` через batch не ставится.

## Стили, текст, краски

- Текстовые стили нельзя переименовать или изменить. `create_text_style` с существующим именем молча возвращает старый — только `delete_style` → create → `apply_style_to_node` заново.
- Описания стилей плагин не читает. `textCase: UPPER` read-инструменты не показывают — смотреть рендер. Ручной `textCase UPPER` отвязывает стиль (Body/Text сам даёт капс).
- `apply_style` сбрасывает курсив → `set_text_range` после. У смешанных текстовых узлов отрезков курсива не отдаёт — смотреть рендер. Кегль строк со смешанными начертаниями — `set_text_range`.
- Трекинг — всегда PERCENT, не PIXELS.
- `boundVariables` на paint сбрасывает blendMode / opacity. Режимы наложения стопки тона и стопы градиентов плагин не отдаёт — подгонка по рендеру.
- Unbounded в Figma ~5 % шире веб-шрифта — высоты текста для Figma брать по факту.

## Картинки

- `get_image_by_hash` не работает (2026-10-02).
- Чтение узла не отдаёт `imageTransform` — перезапись IMAGE у CROP-кадров сбрасывает кадрирование: тонировать слоями поверх или клон в обрезающей рамке.
- Хэш Figma = SHA1 файла, если снимок не пережат; иначе повторы проверять по картинкам.
- Вставка: хэш из временного прямоугольника → `set_fills`.
- Размер исходника — `Image.open(f).size` до `draft()`.

## Узлы и клоны

- Новые фреймы приходят с белой заливкой — `set_fills` с пустым paints.
- Фиксированная высота в auto-layout схлопывается — `layoutSizingVertical: FIXED`. Дети с `layoutPositioning: ABSOLUTE` не укладываются, пока не `resize_nodes` с `AUTO`.
- Клон ложится поверх — проверять порядок слоёв. ID клона с потомками сдвигаются на константу.
- Клоны кадров-стартов и десктопных секций уносят прототип (точки старта, автосмена, реакции) — чистить сразу.
- Клоны с автолейаутом — снимать автолейаут перед раскладкой. Закрытые слоты шириной 0,01 не округлять до 0 (ширина 1 px даёт видимую полосу).
- Корневой фрейм без auto-layout: координаты абсолютные по канве — учитывать смещение фрейма.

## Браузер и сверка

- WebKit под Windows не применяет оси variable-шрифтов → Unbounded статичными 400 / 700.
- WebKit не снимает картинку выше 32 767 px (`shots.py` режет кусками). `full_page`-снимок теряет фото за окном — склейка экранов сдвигом body.
- Постоянный `scrollbar-gutter` сужает headless-окно на 15 px. Плавный скролл в тестах запускает входы — `behavior: 'instant'`. Reload восстанавливает прокрутку и запускает вход до паузы раскадровки.
- Курсор теста под fixed-шапкой не наводит. Длинный снимок элемента не дорисовывает ленту карусели — снимать в окне высоты секции.
- Вертикальное письмо внутри абсолютного слоя в WebKit берёт высоту и длину строки от окна — задавать явно. Растянутые буквы входа дают горизонтальный скролл — `overflow-x: clip`.
- Неразрывные пробелы Figma в узкой колонке дают горизонтальный скролл только с JS — искать отключением секций.
- Ряд `0fr` + `align-items: start` — невидимый элемент перекрывает соседнюю строку (`align-self: stretch`).
- `modulepreload` на телефоне ухудшает LCP фото hero.
- С телефона по Wi-Fi сайт не открылся: порт 8080 закрыт (брандмауэр / AmneziaVPN).
