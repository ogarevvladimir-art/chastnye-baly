2026-10-02 начата вёрстка сайта по макету v2 (`191:626` + адаптив 390 / 834). **Готовый к деплою проект — только
`Частные балы сайт/site/`**: туда кладётся лишь то, что заливается на сервер. План, журнал, инструменты и сверки —
`Доработка/вёрстка/` (ОБЩЕЕ, ЭТАПЫ, ЖУРНАЛ; промты этапов — по запросу, как у адаптива).

Решения пользователя: хостинг — российский с PHP (FTP, `.htaccess`, `send.php`); куда идут заявки и нужна ли аналитика —
«решу позже» (вопрос на этапе 6). Стек, который я предложил: чистые HTML / CSS / ES-модули без сборки и GSAP; шрифты свои
(без Google Fonts); Figma только читать.

`Прототип/` — старый дизайн (Manrope, схемы), из него брать только мета-теги и текст privacy.

**Этап 0 закрыт 2026-10-02**, роли утверждены. Решения пользователя: шире 1440 — vw до окна 1920, дальше композиция по центру;
крупные роли масштабируются **от колонки** (`--u` = (окно − 2 поля) / 358 · 770 · 1312, окно — `--vw` из clientWidth), а не от vw
ПЕРЕДАЧА. Набор в браузере совпадает с Figma до 0,34 % (`tools/type_check.py`). Текст — `Доработка/вёрстка/ТЕКСТ.md`.
Грабли: скриншоты figma-mcp-express пишутся только внутрь `VS CODE/`; описания стилей плагин не читает; у смешанных
текстовых узлов нет отрезков курсива — смотреть рендер; WebKit не снимает картинку выше 32 767 px (shots.py режет кусками).
