В ответах пользователю секции и кадры Figma называть так, как они подписаны в Figma (например, «Д3б · 06 / 07 / 08 в экран · варианты A / B (2026-10-05)»), а не id вроде `328:2278`.

**Why:** 2026-10-05 пользователь: «для меня названия секций выглядят по-другому — исправь на названия, которые я вижу». Id в интерфейсе Figma не видны, по ним секцию не найти.

**How to apply:** в чате — видимое имя (id можно дать в скобках вторым, если он нужен для дела). В ЖУРНАЛ и скриптах id оставлять: по ним работают инструменты. Связано с [[project-chastnye-baly]].
