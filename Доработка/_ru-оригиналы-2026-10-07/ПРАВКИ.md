# Правки по сайту

Сбор замечаний после просмотра сайта с анимациями (с 2026-10-03). Порядок работы:

1. Пользователь присылает в чат по одному замечанию — описание и скриншоты.
2. Claude разбирает его: находит место в коде и макете, называет причину и задаёт вопросы. Запись в этот файл —
   только после подтверждения пользователя.
3. Когда пользователь скажет, что правок больше нет, Claude систематизирует список (группы, повторы, зависимости,
   приоритеты), задаёт вопросы и после ответов пишет план изменений.

Пока идёт сбор, код в `site/` не меняется.

Скриншоты пользователь кладёт в `Доработка/Скрины правок/` («Правка N.jpg»); в записи — ссылка на файл.

## Шаблон записи

```
### П-NN · <блок> · <ширины / устройство>
- Замечание: своими словами пользователя
- Сейчас: что видно на сайте и почему (селектор, файл, решение этапа или макет)
- Как должно быть: что подтвердил пользователь
- Тип: ошибка вёрстки / расхождение с макетом / изменение дизайна / анимация / текст / поведение
- Затрагивает: файлы и блоки; нужна ли правка Figma
- Скриншоты: Доработка/Скрины правок/Правка N.jpg
- Вопросы: открытые (если остались)
```
